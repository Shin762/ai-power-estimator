# AI電力試算 / AI Power Estimator

日本語 | [English](README.en.md)

AIの利用量から、推論にかかる電力量・CO₂排出量・電気代換算を概算する Web ツールです。すべての係数に出典と時点を付け、「どのくらいの大きさか」を根拠付きで把握できるようにしています。

## 目的

AI需要の急増で、データセンターが集中する地域の電力網が逼迫し、一般家庭の電力供給や電気料金にまで影響が及ぶリスクが指摘されています。本プロジェクトは、AIの電力消費を**見える化**し、次の2つに役立てることを目指します。

1. **社会的な電力不足の回避**
   AI需要による地域電力網の逼迫を防ぐため、電力側とAI企業が負荷（いつ・どこで・どれだけ計算するか）を調整するための共通の物差しを提供する。
2. **地方分散の推進**
   エッジ推論や地方型データセンターへの分散によって、特定地域への負荷集中を緩和する選択肢を、数字で比較・検討できるようにする。

現在のバージョンはその第一段階として、個人・サービス単位の推論電力を試算します。

## ターゲット

| 対象 | 主な関心 |
|---|---|
| AIを日常的に使う個人 | 自分の使い方でどのくらい電力を使っているか |
| AIを組み込んだサービスの開発者・企画担当 | モデル規模・トークン数・リクエスト数から見た推論電力 |
| 自治体・電力会社・政策担当者（今後） | 地域ごとのAI電力需要と、電力網への影響 |
| データセンター事業者・AI企業（今後） | 負荷の時間シフト・地域分散の効果 |
| 教育関係者・記事執筆者 | 出典付きで引用できる目安の数字 |

## 使う場面

- **個人**：使い方の振り返り、LED電球やスマートフォン充電に置き換えた説明
- **開発者**：モデル規模の選定（小型と大型で何倍違うか）、プロンプト・出力の短縮効果の見積もり
- **企業**：企画書や社内説明、環境報告のたたき台（算定範囲が揃わないため、開示値としての利用は不可）
- **地域・電力（今後）**：AI需要の積み上げと電力網容量の比較、負荷調整・分散配置の検討

## 現在の機能

- **個人のチャット利用**：1回あたりの電力量（Gemini / ChatGPT の公表値、外部推計、カスタム）× 回数、画像生成を加味
- **API / トークン単位**：アクティブパラメータ数・入出力トークン数・月間リクエスト数から、GPU性能・利用率・サーバー付帯係数・PUE を前提に推計
- **共通**：月間・年間の電力量、CO₂排出量（排出係数は変更可）、電気代換算、身近な機器との比較

## 前提と注意

- 対象は推論（利用時）の電力のみです。モデルの学習、端末・通信ネットワーク、データ保存の電力は含みません。
- 公表値は各社の自己申告または外部推計で、算定範囲が揃っていません。桁感をつかむための概算として使ってください。
- 各係数の出典と時点は [`src/data/factors.ts`](src/data/factors.ts) とアプリ画面下部に記載しています。

## 開発

必要環境：Node.js（v24 で動作確認）

```bash
npm install
npm run dev      # 開発サーバー
npm test         # テスト（Vitest）
npm run build    # 型チェックとビルド（dist/ に出力）
```

技術スタック：React 19 / TypeScript / Vite / Vitest
